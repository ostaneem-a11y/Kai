KAI V1 — PHONE SETUP

IMPORTANT:
Android/Chrome normally blocks microphone access when index.html is opened directly from Downloads.
Kai must be opened from a secure HTTPS website.

EASIEST SETUP:
1. Upload the files in this folder to any HTTPS static website host.
2. Open that HTTPS address in Chrome on your Android phone.
3. Allow microphone permission when Chrome asks.
4. Tap the microphone.
5. Optional: Chrome menu (⋮) -> Add to Home screen / Install app.

FILES:
- index.html = Kai
- manifest.webmanifest = installable web-app settings
- sw.js = offline shell

DO NOT:
- Do not open index.html directly from the Downloads/File Manager and expect microphone access.
- Do not give your AI API key to browser code. The AI brain should use a small secure server/backend in the next version.
